Notes

Decontamination stated without naming benchmarks: 'Gemini 1.5 employed standard n-gram based decontamination procedures to help mitigate this issue, however these n-gram based procedures are imperfect.' (Section 6.1). The report also says controlling HumanEval leakage on webpages and open-source repositories was 'a non-trivial task, even with conservative filtering heuristics', and shows (for Gemini 1.0 Ultra) that one epoch of the HumanEval test split raised scores from 74.4% to 89.0%; that experiment is not a finding about Gemini 1.5's training data. Checkpoints are the IDs in the Gemini 2.5 report Table 2; earlier -001 versions existed. Accepts image input: “since the model is natively multimodal and supports interleaving of data from different modalities, it can support a mix of audio, visual, text, and code inputs in the same input sequence.”
