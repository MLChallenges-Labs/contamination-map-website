Notes

The image encoder is initialised from an MAE pre-trained ViT-H. The SAM paper does not state the MAE pre-training data. The MAE paper (https://arxiv.org/pdf/2111.06377v3, Section 4) says 'We do self-supervised pre-training on the ImageNet-1K (IN1K) training set', but SAM does not say which MAE checkpoint it used. disclosure is partial_list for that reason. In the data engine's first stage, SAM was first trained on common public segmentation datasets, then 'retrained using only newly annotated masks' (Section 4). The released model is described as trained on SA-1B.
