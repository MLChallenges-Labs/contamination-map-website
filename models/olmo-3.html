Notes

7B (Oct 2025) and 32B (Nov 2025) bases were released together on 2025-11-20 and draw on the same Dolma 3 pools with size-specific mixes. Base-model decontamination covers midtraining and long-context data only (any split of OLMES benchmarks, incl. GSM8K, MATH, HumanEval, MMLU, ARC, HellaSwag, WinoGrande per OlmoBaseEval); the 5.9T-token stage-1 web/PDF/code mix is not stated to be decontaminated. Post-training exclusions list the Table 16 benchmarks that map to registry ids (also BBH, ZebraLogic, AGI Eval, HumanEval+, MBPP+, IFEval, IFBench, AlpacaEval, PopQA). Midtraining includes synthetic data generated from the MATH training set (TinyMATH).
