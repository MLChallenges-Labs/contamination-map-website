Notes

Training-free: frozen OpenCLIP ViT-B/16+ (LAION-400M) with a compositional prompt ensemble; no learned parameters, so no extra training data. WinCLIP+ (few-shot) stores patch features of k normal reference images from the target dataset's normal training split in a memory bank at inference (no training). No official code or weights; the InCTRL authors state the official implementation is not publicly available and released a reproduction (github.com/mala-lab/WinCLIP).
