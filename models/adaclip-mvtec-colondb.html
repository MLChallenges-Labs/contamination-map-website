Notes

Hybrid static/dynamic learnable prompts in a frozen CLIP ViT-L/14-336 (OpenAI). Used (test.sh) for all evaluations except MVTec AD and ColonDB: VisA, MPDD, BTAD, SDD (KolektorSDD), DAGM, DTD-Synthetic and medical sets. The paper text says MVTec AD & ClinicDB; the README 'Corrections' section says MVTec AD & ColonDB, which matches the code (test.sh, HF Space app). README training recipe uses the target-side dataset (e.g. VisA) as validation set to pick the best epoch ('choose the best model based on performance on the validation set').
