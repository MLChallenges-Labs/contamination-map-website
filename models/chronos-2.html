Notes

120M-parameter main model; autogluon/chronos-2-small (28M) is listed here because its model card declares the same datasets metadata (autogluon/chronos_datasets, Salesforce/GiftEvalPretrain) and the paper describes it only as 'a small model with 28M parameters' (ablation, Section 5.4). Real data is univariate only (Table 6: 23 datasets, from the Chronos corpus and GIFT-Eval pretrain); all multivariate/covariate data is synthetic. Trained on GIFT-Eval pretrain data and partially on GIFT-Eval datasets' training portions; GIFT-Eval test portions explicitly excluded. Which subset of GIFT-Eval Pretrain and which time ranges were used is not specified. Chronos-2 is two-stage (2048 context pre-training, then 8192 context post-training); the data of each stage is not separated. Other stated exclusions, not tracked here: fev-bench (all); chronos-benchmark-ii (all).
