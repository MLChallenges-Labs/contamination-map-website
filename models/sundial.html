Notes

Paper describes Small/Base/Large sizes; only Base (128M) is released. Model card metadata lists datasets thuml/UTSD, Salesforce/lotsa_data, autogluon/chronos_datasets. In Sundial Table 1, Time-MoE's ECL and TimesFM's ECL/Weather cells are dashes (pre-training data). TimeBench includes LOTSA and the Chronos data; the authors state all evaluated datasets were excluded from it, so LOTSA is not linked directly.
