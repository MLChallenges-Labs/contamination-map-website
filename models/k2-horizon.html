Notes

One entry for the family: all six cards point to the same data release (IFM/TxT360-v2 and the K2 Horizon dataset series), but per-size recipes differ: 3.7B/7B/32B/MoVA cards list 22.9T pre-training tokens, 375B-A23B lists two phases (7.08T + 8.05T), 0.9B lists 5T plus multi-teacher distillation; post-training differs (SFT only for 32B and MoVA; RL experts + merge + SFT for 3.7B/7B/375B; RL + on-policy distillation for 0.9B). No technical report yet (cards dated 2026-09-28 say end of September 2026). The ifm.ai blog returned HTTP 403 to automated fetches, so nothing is quoted from it.
