Notes

Training-free and transductive: at inference, the unlabelled TEST images of the target dataset score each other (Mutual Scoring Mechanism), and RsCIN re-scores image-level results using the image-level neighbourhood over the test set. No parameters are fitted, so no training entry; but results depend on the whole unlabelled test set being available ('we propose the first method that only uses the unlabeled test images'). Code also supports OpenCLIP LAION-400M, DINO and DINOv2 backbones (paper appendix/README ablations); the reported default is OpenAI CLIP ViT-L/14-336.
