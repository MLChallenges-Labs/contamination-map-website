Vision / Benchmark

ImageNet and natural distribution shifts

ImageNet-1k accuracy plus five test sets that keep (a subset of) the ImageNet classes but change the images: a re-collected test set (ImageNetV2), sketches (ImageNet-Sketch), renditions (ImageNet-R), adversarially filtered natural images (ImageNet-A) and bias-controlled photographs (ObjectNet). Grouping used on this site, not an official suite: it follows the natural distribution-shift evaluation popularised by the CLIP paper (Section 3.3) and the CLIP_benchmark / DataComp suites. Models are evaluated zero-shot (class names in text prompts) or with an ImageNet-trained classifier.

Test split: Only test images are scored. ImageNet-1k: the 50,000-image ILSVRC 2012 validation set (test labels were never released). The five shift sets are test-only and evaluated in full: ImageNetV2 MatchedFrequency (10,000), ImageNet-Sketch (50,889 files), ImageNet-R (30,000; 200 classes), ImageNet-A (7,500; 200 classes), ObjectNet (the 18,574 images of its 113 ImageNet-overlapping classes). Sizes as listed by the DataComp task list; split choices as loaded by CLIP_benchmark.

Notes

These sets reuse ImageNet class names, so a model trained on ImageNet-1k has seen the label space but not these images (except where a relation says so: ImageNetV2 same collection process; ImageNet-R reuses ImageNet-Sketch line drawings). Their images (except ObjectNet's) are public web photos, so web-scale pre-training can contain them.
