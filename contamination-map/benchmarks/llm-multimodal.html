Multimodal LLM benchmarks

Commonly reported multimodal LLM benchmarks; grouping used on this site, not an official suite. Covers multi-discipline expert QA (MMMU, MMMU-Pro), visual math (MathVista), charts (ChartQA, CharXiv), documents (DocVQA) and science diagrams (AI2D).

Test split: Split usually evaluated (as configured in lmms-eval): MMMU validation (900; mmmu_val; test 10,500 answers public since 2026-02-12); MMMU-Pro the single 1,730-question test split in 'standard (10 options)' and 'vision' configs (answers public); MathVista testmini (1,000; answers public; test 5,141 answers private); ChartQA test (2,500 = 1,250 human + 1,250 augmented; public); DocVQA test (5,188; answers private, scored by submission to the RRC server) or validation (5,349; public); AI2D test (3,088 in lmms-lab/ai2d; all AI2D answers are in the public download); CharXiv validation (1,000 charts; reasoning and descriptive tasks; test answers private).
