Vision / Dataset

ImageNet-A

7,500 real-world, unmodified images of 200 ImageNet-1k classes, adversarially filtered: images that fixed ResNet-50 classifiers predicted correctly were removed, then the rest manually checked. Test-only: all 7,500 images are evaluated, restricted to the 200-class subset of ImageNet labels.

Also known as
ImageNet Adversarial, imagenet-a, wds/imagenet-a, IN-A
Domain
object recognition (adversarially filtered natural images)

Notes

Images exported or scraped from iNaturalist, Flickr and DuckDuckGo (Section 3.1); not ImageNet images, so no relation to imagenet-1k is recorded. The selection depends on ResNet-50 errors, so the set is adversarial to ImageNet-trained CNNs specifically. The companion ImageNet-O (out-of-distribution detection) is built from ImageNet-22K and is not part of this grouping. Paper v1: 16 Jul 2019. published_from is left empty: the test images were public on the web before the dataset was released, so a release date would not bound what a web crawl could contain.
