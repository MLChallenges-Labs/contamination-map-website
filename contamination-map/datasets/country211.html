Country211

Geolocation classification dataset created by OpenAI for the CLIP paper: YFCC100M photos with GPS coordinates, labelled with one of 211 countries (ISO-3166 codes). The released version has 150 training, 50 validation and 100 test images per country; the 21,100-image test split is evaluated.

Notes

A subset of YFCC100M (not in the registry); the photos were on Flickr long before the dataset (CLIP paper v1: 26 Feb 2021). The CLIP paper describes 200 training and 100 test photos per country, the released README 150/50/100. The CLIP paper reports its largest detected train-test overlap for Country211 because its pre-training data contains a filtered subset of YFCC100M (to be recorded on the model). published_from is left empty: the test images were public on the web before the dataset was released, so a release date would not bound what a web crawl could contain.
