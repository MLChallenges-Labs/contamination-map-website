Vision / Dataset

Real-IAD

Real-world, multi-view industrial anomaly detection dataset: about 150K high-resolution images (151,050 in the paper's comparison table) of 30 objects, each captured from 5 viewpoints, with pixel-level masks for anomalous images. Benchmark protocols: Unsupervised IAD (training set contains only normal samples; test set contains normal and anomalous samples) and Fully Unsupervised IAD (0-40% anomalous images added to the training set). Distributed as realiad_1024 (1024x1024), realiad_raw and JSON split files.
