Vision / Dataset

ImageNet-1k (ILSVRC 2012)

Image-classification subset of ImageNet used in ILSVRC 2012-2017: 1,000 object classes, 1,281,167 training, 50,000 validation and 100,000 test images. Test labels were never released, so the 50,000-image validation set is what is evaluated as 'ImageNet accuracy', including in zero-shot evaluation (CLIP_benchmark `imagenet1k` loads the `val` split for its test split).

Notes

Validation and test photographs were 'collected from flickr and other search engines' and, per the ILSVRC2012 page, are not part of the previously published ImageNet and are de-duplicated against the training data. Development kit, training and validation data were released on 16 June 2012, test images on 10 July 2012 (ILSVRC2012 timetable). published_from is left empty: the test images were public on the web before the dataset was released, so a release date would not bound what a web crawl could contain. ImageNet-1k is a subset of the full ImageNet database (ImageNet-21k/22k); that dataset is not in this grouping.
