Notes

Modality set to text because the language backbone is evaluated on text benchmarks; the model also takes images. Built on the Llama 3.1 text model, so the llama-3.1 contamination findings may apply to its language backbone (not stated by Meta). Accepts image input: “Llama 3.2-Vision models come with multimodal (text and image) input capabilities enabling image reasoning applications.” Accepts image input: “The Llama 3.2-Vision instruction-tuned models are optimized for visual recognition, image reasoning, captioning, and answering general questions about an image.”
