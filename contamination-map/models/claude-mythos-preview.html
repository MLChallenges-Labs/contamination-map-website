Notes

Included because its system card has the most detailed Anthropic contamination analysis (Section 6.2), which the Claude 5 system cards cite for SWE-bench memorisation screening. Decontamination follows the Claude Opus 4.5 methodology plus perceptual-hash removal of training images matching multimodal evaluation images ('We take several steps to decontaminate our evaluations; see Section 2.2 of the Claude Opus 4.5 System Card'). No API model ID or stated knowledge cutoff; training_cutoff is the EU summary's latest data acquisition date. EU summary is an AIAL-hosted copy of Anthropic's document (Anthropic's trust portal is not fetchable). Accepts image input: “Claude Mythos Preview can understand both text and image inputs, engaging in conversation, analysis, coding, and creative tasks.” Exclusion not shown as a cell (names no tracked benchmark): images contained in multimodal evaluations (perceptual-hash match).
