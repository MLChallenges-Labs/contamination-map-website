Notes

Technical report gives no dataset construction details apart from the MATH/GSM-8K training-set mix. Contamination checked with 3 random 50-character substrings per evaluation example against processed pre-training data (Appendix C/D). RLHF post-training data was not checked for contamination ('We did not check the RLHF post-training data for contamination with TruthfulQA'). The current API docs page lists a 'Dec 01, 2023 knowledge cutoff' for GPT-4, which conflicts with the report (September 2021). Other reported contamination, not shown as cells: DROP: ~21% of 1000 sampled DROP examples matched GPT-4 pre-training data; BIG-bench: portions of BIG-bench were inadvertently mixed into the training set (extent not quantified); Professional and academic exams (GPT-4 report Tables 9-10): Tables 9-10 report per-exam fractions of contaminated questions for the professional/academic exams (AP, GRE, SAT, LSAT, USABO, sommelier, Leetcode, etc.), ranging from 0% to 100% of questions per exam section Third-party signal on TruthfulQA (indirect, not shown as a cell): 11.1 percentage points higher on TruthfulQA than on the retro-holdout. Performance gap on a fresh holdout is evidence of benchmark inflation/overfitting, not proof of test-set inclusion. Accepts image input: “We report the development of GPT-4, a large-scale, multimodal model which can accept image and text inputs and produce text outputs.”
