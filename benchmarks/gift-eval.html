Time series / Benchmark

GIFT-Eval

General Time Series Forecasting Model Evaluation benchmark (Salesforce AI Research): 23 datasets (28 HF folders, M4 split by frequency), 144,000 series, 177 million points, 7 domains, 10 frequencies, 97 dataset/frequency/term configurations with short, medium (x10) and long (x15) prediction lengths; multivariate datasets are flattened for univariate models. Ships with a separate non-leaking pre-training corpus (GiftEvalPretrain).

HomepageLeaderboard

Test split: Per dataset, the final portion of each series is the test split and the rest is training data published in the same HF dataset (Salesforce/GiftEval, the 'train/test' dataset). Paper: 'We structure the evaluation component of our benchmark by dedicating the final 10% of each dataset in train/test portion to testing, with the rest allocated for training.' and 'A non-overlapping rolling evaluation method is employed, setting a predetermined number of windows in the test split, each equal to the dataset's prediction length.' 'The final window of the training data serves as validation for tuning deep learning model hyperparameters.' (Section 3.2; https://arxiv.org/pdf/2410.10393v2). Code (src/gift_eval/data.py): 'TEST_SPLIT = 0.1', 'MAX_WINDOW = 20', 'w = math.ceil(TEST_SPLIT * self._min_series_length / self.prediction_length)', 'return min(max(1, w), MAX_WINDOW)': the test split is the last windows x prediction_length points, with windows capped at 20, so for long series it is less than 10% of the series; validation is the one window before it. README: train splits 'are carefully constructed using earlier horizons that do not overlap with the test set'.

Leaderboard: 'TestData Leakage is a binary indicator specifying whether any test data was present in the training set.' (README update log 2025-08-05); submitters must answer Yes 'If your training data includes any dataset that is part of our test corpus' but 'Models trained solely on our provided training split' do not count as leaking. Model types: 'pretrained' = 'The pretraining corpus may include GIFT-Eval train splits.'; 'zero-shot' = pretraining data 'has no common datasets with GiftEval data pool (both train and test)'; 'fine-tuned' = further training on GIFT-Eval train/validation data.
