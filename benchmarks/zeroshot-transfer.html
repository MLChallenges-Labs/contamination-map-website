Vision / Benchmark

Zero-shot transfer classification

Sixteen image-classification datasets outside ImageNet (objects, fine-grained categories, textures, scenes, satellite and aerial images, traffic signs, digits, geolocation) used to test whether image-text models transfer to new label sets without training on them. Grouping used on this site, not an official suite: it is the subset of the evaluation suite popularised by the CLIP paper (Table 9) that CLIP_benchmark and DataComp also run.

Test split: The test split of each dataset is scored, as listed per dataset. Several datasets have no official test split and suites differ: Caltech-101, EuroSAT, RESISC45 use the VTAB splits in CLIP_benchmark and DataComp (CLIP used its own sizes); SUN397 is scored on all 108,754 images in CLIP_benchmark / DataComp but on 19,850 test images in CLIP. Metrics: accuracy, except mean per-class accuracy for FGVC-Aircraft, Oxford-IIIT Pet, Caltech-101 and Flowers-102 (CLIP Table 9, DataComp).

Notes

Excludes datasets of the CLIP/DataComp suites that are not in this grouping (e.g. Birdsnap, Pascal VOC 2007, FER2013, KITTI, PatchCamelyon, CLEVR, Rendered SST2, SVHN). Several sets are public web images (Country211 comes from YFCC100M, which CLIP's pre-training data partly contains), so web-scale pre-training can contain test images.
