Classic LLM benchmarks

Commonly reported LLM benchmarks; grouping used on this site, not an official suite. Covers knowledge (MMLU), math (GSM8K, MATH), code (HumanEval), science QA (ARC-Challenge), commonsense (HellaSwag, WinoGrande) and truthfulness (TruthfulQA).

Test split: Split usually evaluated (as configured in EleutherAI lm-evaluation-harness, which uses the test split when defined, otherwise validation): MMLU test (14,042 in cais/mmlu; 5-shot from dev); GSM8K test (1,319); MATH test (5,000; many recent reports use MATH-500 instead); HumanEval all 164 problems (only split); ARC-Challenge test (1,172); HellaSwag validation (10,042; harness test_split is null); TruthfulQA validation (817; only split); WinoGrande validation/dev of winogrande_xl (1,267; test labels are not released).
