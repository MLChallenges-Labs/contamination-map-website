Recent LLM benchmarks

Commonly reported LLM benchmarks; grouping used on this site, not an official suite. Harder reasoning, math, science and coding benchmarks typical of 2024-2026 model reports.

Test split: GPQA Diamond: all 198 questions (no train/test split). MMLU-Pro: test (12,032; the 70-question validation split supplies few-shot examples). LiveCodeBench: code-generation problems inside a release-date window (this site: release_v6, May 2023 - Apr 2025, 1,055 problems; reports often use a later sub-window). SWE-bench Verified: the 500-instance test set. AIME 2024 / AIME 2025: all 30 problems of AIME I and II. MATH-500: the 500-problem test.jsonl from PRM800K.

Scores · Epoch AI Benchmarking Hub (Epoch's own runs)

Accuracy (fraction), mean over every dataset (one run per model version and dataset); higher is better. From Epoch AI Benchmarking Hub (Epoch's own runs) at benchmark_da (CC-BY-4.0), retrieved 2026-10-16. Only Epoch's own evaluations are used (gpqa_diamond.csv, swe_bench_verified.csv); the *_external.csv files in the same archive collect numbers from other papers and are not used. GPQA Diamond: all 198 questions, simple-evals style prompt asking for 'ANSWER: LETTER', strict parsing, accuracy averaged over samples (https://epoch.ai/benchmarks/gpqa-diamond). SWE-bench Verified: Epoch scaffold v2.0 (since 2026-02-12; bash + text_editor/apply_patch tools, token budget), on 484 of the 500 Verified instances that run on Epoch's infrastructure, so it is a 96.8% subset of the registry dataset (https://epoch.ai/benchmarks/swe-bench-verified). 'score' is Epoch's headline column 'Best score (across scorers)', equal to mean_score except for 5 GPQA rows. Entry names carry the reasoning setting (_high, _max, _16K thinking budget, _none = thinking off); the primary entry of each model is the one scored on most of this source's datasets, then the highest reasoning setting, then the latest snapshot. Two SWE-bench model versions with two runs keep the latest run (neither maps to a registry model). Scores are fractions in [0, 1]. Other Epoch entries not listed belong to models absent from the registry. The coloured bar shows how much of this benchmark each model may have seen.

Accuracy (%), mean over every dataset (30 problems x 4 attempts per model); higher is better. From MathArena (AIME 2025 model outputs) at 16e93d3bb9b0 (CC-BY-NC-SA-4.0), retrieved 2026-10-16. MathArena ran every model itself on AIME 2025 I+II (30 problems, MathArena/aime_2025), 4 attempts per problem, same instruction ('Put your final answer within \boxed{}. The answer is an integer between 0 and 999 inclusive.'), automatic answer parsing; per-model API settings (max_tokens, temperature, reasoning effort) follow each model config in eth-sri/matharena configs/models. Accuracy = share of correct attempts, computed here from the per-attempt 'correct' field of the outputs parquet. Licence is CC BY-NC-SA 4.0 (non-commercial, share-alike): republishing the numbers is allowed for non-commercial use with attribution and the same licence. MathArena publishes no AIME 2024 outputs (only problem sets), so aime-2024 is not covered. Entries not listed belong to models absent from the registry.
