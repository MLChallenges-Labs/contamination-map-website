Soil Moisture Active Passive (SMAP) telemetry anomaly dataset

Real telemetry of NASA's Soil Moisture Active Passive satellite released by NASA JPL with Telemanom (Hundman et al., KDD 2018): 55 anonymised telemetry channels, each with one telemetry value plus one-hot encoded command information (25 dimensions in the OmniAnomaly table), 69 expert-labelled anomaly sequences (from Incident Surprise, Anomaly reports). Pre-split train and test sets per channel; labels refer to the test set; values are pre-scaled to (-1,1) using the test-set min/max and timestamps are anonymised. OmniAnomaly statistics: 135,183 training and 427,617 test points, anomaly ratio 13.13%.
