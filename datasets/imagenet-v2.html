ImageNetV2 (MatchedFrequency)

New test set for ImageNet built by replicating the original ImageNet collection process (Flickr search, MTurk labelling) for the same 1,000 classes. Three variants of 10,000 images each (10 per class) exist: MatchedFrequency, Threshold0.7 and TopImages. MatchedFrequency is the one used here and by CLIP_benchmark (`imagenetv2`, variant matched-frequency). Test-only: all 10,000 images are evaluated.

Notes

Images are Flickr photos taken and uploaded between 11 July 2012 and 11 July 2014 (paper, Appendix C.1.1), later than the ImageNet collection; near-duplicates of the original ImageNet images were removed, so the same_source relation means same classes and collection process, not shared images. Paper v1: 13 Feb 2019. published_from is left empty: the test images were public on the web before the dataset was released, so a release date would not bound what a web crawl could contain.
