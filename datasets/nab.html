Numenta Anomaly Benchmark (NAB)

58 labelled real-world and artificial time-series data files (1,000-22,000 points each, 365,551 points in total) from sources such as AWS server metrics, Twitter volume, advertisement clicks and traffic data, with hand-labelled anomaly windows and a scoring scheme for streaming detection. No train/test split: detectors run online over each file and the first 15% of each file is an unscored probationary period.
