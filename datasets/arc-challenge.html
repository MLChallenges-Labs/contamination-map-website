ARC-Challenge (AI2 Reasoning Challenge, Challenge Set)

Challenge Set of the ARC grade-school science multiple-choice questions: 2,590 questions answered incorrectly by both a retrieval-based and a word co-occurrence baseline; train 1,119 / dev 299 / test 1,172. (The full ARC set has 7,787 questions; the Easy Set has 5,197.)

Notes

Subset of the full ARC question set (no registry id for full ARC / ARC-Easy). Questions were authored for human standardized tests; the paper says ARC includes the publicly releasable subset of the Kaggle questions. Copies found in public web data by third-party studies: Common Crawl: 336 of 1172 ARC-Challenge test examples (28.7%) flagged as present in Common Crawl (Oct 2020-Oct 2023 window); 283 (24.1%) with question and answer.
