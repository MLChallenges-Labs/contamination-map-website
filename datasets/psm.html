Pooled Server Metrics (PSM)

Multivariate server metrics collected internally from multiple application server nodes at eBay, released by eBay with RANSynCoders (Abdulaal et al., KDD 2021). The repository provides train.csv (no labels), test.csv and test_label.csv; the csv files have a minute timestamp column and 25 anonymised features (feature_0 to feature_24).
