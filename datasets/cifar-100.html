Vision / Dataset

CIFAR-100

60,000 32x32 colour images in 100 classes grouped into 20 superclasses, 600 per class: 500 training and 100 test images per class. The 10,000-image test set is evaluated.

Also known as
CIFAR100, vtab/cifar100, wds/vtab/cifar100, tfds/cifar100
Domain
general object recognition (low resolution)
Homepage
www.cs.toronto.edu

Notes

Labelled subset of the 80 Million Tiny Images dataset (web search results), like CIFAR-10; no image overlap between CIFAR-10 and CIFAR-100 is stated by the sources read, so no relation is recorded. The CLIP paper notes that many detected CIFAR-100 duplicates in its overlap analysis were false positives due to the very low resolution. published_from is left empty: the test images were public on the web before the dataset was released, so a release date would not bound what a web crawl could contain.
